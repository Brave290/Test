# Phantom Creative - Premium Graphics Design Studio

A modern, full-featured website for a graphics design studio with user authentication, admin dashboard, blog, portfolio, and email system.

## Features

- ✅ User Authentication (Email/Password)
- ✅ Admin Dashboard with Full CMS Control
- ✅ Blog Management System
- ✅ Portfolio Gallery Management
- ✅ Testimonials Management
- ✅ Services Management
- ✅ Contact Form with Database Storage
- ✅ Newsletter Subscription System
- ✅ Auto Email Notifications (Contact Form, Welcome Emails, Blog Alerts)
- ✅ Responsive Design (Mobile, Tablet, Desktop)
- ✅ Modern UI with Animations
- ✅ Firebase Backend

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, TailwindCSS
- **Backend**: Firebase (Auth, Database, Storage, Cloud Functions)
- **Email**: Nodemailer with Gmail SMTP
- **Hosting**: Vercel

## Email Configuration

The website uses Firebase Cloud Functions with Nodemailer to send:
- 📬 Contact form submissions to the admin
- 🎉 Welcome emails to new subscribers
- 📝 Newsletter alerts to all subscribers when new blog posts are published
